# AS Research Pub — Open Access Academic & Scientific Publishing

AS Research Pub is an open-access, peer-reviewed international academic publishing platform providing fast review cycles, CrossRef DOI assignment, and rigorous editorial standards for scholars, researchers, and institutional authors.

## 🌟 Key Features
- **Peer-Reviewed Journals Catalog**:
  - *International Journal of Advanced Engineering & Computing* (ISSN: 2583-1011)
  - *Journal of Modern Business Strategy & Economics* (ISSN: 2583-1028)
  - *Journal of Applied Scientific Research & Innovation* (ISSN: 2583-1044)
- **Transparent APC Structure**:
  - Standard Indian Researchers: ₹1,500 / paper
  - Fast-Track Indian Scholars: ₹2,500 / paper (48-hour priority review)
  - International Authors: $50 / paper
- **Interactive Scholar Tools**:
  - Research article repository with keyword search and disciplinary filters
  - 1-click citation export (APA 7th, BibTeX, MLA 9th, Chicago)
  - In-browser scholarly paper preview
  - Online manuscript submission portal with instant tracking ID generation
  - AI Research Assistant floating chatbot widget

## 🚀 Live Preview / Running Locally
You can run this project locally using Python's built-in HTTP server:
```bash
python3 -m http.server 3000
```
Then open [http://localhost:3000](http://localhost:3000) in your browser.
